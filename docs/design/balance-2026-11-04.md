# Balance sweep — round length (2026-11-04)

After ball flight (see `balance-2026-10-21.md`) a round scored about 4 points
in total: a playtest at 390×844 ended 2–0. That doc named the lever: the
client's round clock, not the engine. The clock now lives in
`client/game/roundClock.js`, which both `CourtCanvas.vue` and
`scripts/balance-sweep.mjs` import, so the sweep plays the round players
watch. The sweep takes regulation and OT lengths (sim seconds) as optional
arguments for trying a change before making it:

    node scripts/balance-sweep.mjs [engineDir] [sims] [regSecs] [otSecs]

## Change

Regulation went from 12 s on screen (30 s of sim) to **20 s on screen (50 s
of sim)**. Speed stays 2.5x, so motion looks the same; OT stays 6 s on
screen (15 s of sim). Engine unchanged (shared-core `04d9ad1`).

## Result (1000 fights per matchup)

| | before (30 s) | after (50 s) |
|---|---|---|
| random mirror, home win | 51% | **49%** |
| top-cost five vs bottom-cost five, home win | 82% | **87%** |
| total points, mirror | 4.2 | **6.7** |
| total points, top vs bottom | 4.7 | **8.0** |
| avg score, top vs bottom | 3.5–1.2 | 5.8–2.2 |
| avg score, mirror | 2.3–1.9 | 3.5–3.2 |
| scoreless games (mirror) | 5% | **2%** |
| shots per game (mirror) | 4.4 | 7.0 |
| bunching / teleports per s | 0.00 / 0.06 | 0.00 / 0.06 |

Both were run with the same engine on the same day:
`node scripts/balance-sweep.mjs public 1000 30 15` and
`node scripts/balance-sweep.mjs public 1000`.

## What the sweep found (500 fights each unless noted)

| regulation (sim s) | on screen at 2.5x | mirror home win | top vs bottom | total points (mirror / top-bottom) |
|---|---|---|---|---|
| 30 | 12 s | 48% | 81% | 4.3 / 4.7 |
| 45 | 18 s | 51% | 86% | 6.1 / 7.0 |
| 50 (1000 fights, two runs) | 20 s | 50%, 48% | 85%, 85% | 6.6 / 7.9 |
| 60 (OT 18) | 24 s at 2.5x, or 20 s at 3x | 55% | 90% | 7.8 / 9.1 |

- Longer rounds let talent compound: top vs bottom rises with every second
  (81 → 86 → 85–87 → 90%). 60 s left the 80–88% band, and the mirror drifted
  to 55%, so 50 s is the longest round that keeps both targets.
- 50 s lands both matchups inside the 6–10 point target and halves scoreless
  games. 20 s on screen keeps a phone round short: add the 1.8 s tip-off card
  and the 1.5 s hold after the horn (plus up to 6 s of OT in a tie).
- With 500–1000 fights a win rate moves ±2–4 points between runs (see the two
  50 s runs), so read the table as a band, not a decimal.

## Open

- Top vs bottom at 85–87%, near the top of the band. If real runs feel like

- The JS backup ref (`client/game/fallbackSim.js`, used only when the WASM
  engine fails to load) plays the same longer clock; it was not swept.
